# Набір портфоліо-сайтів

Незалежні Next.js-проєкти українською мовою:

- `cosmetology` — ÉLAN Clinic
- `agro` — TerraNova Agro
- `dentistry` — Forma Dental
- `florist` — Fleur Room
- `furniture` — Nord Form
- `car-import` — WestDrive Import

У кожній теці виконайте:

```bash
npm install
npm run dev
```

Для production-перевірки: `npm run lint`, `npm run typecheck`, `npm run build`.
