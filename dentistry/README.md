# Forma Dental

Сучасний сайт стоматології українською.

```bash
npm install
npm run dev
npm run lint
npm run typecheck
npm run build
```

Перед запуском замініть контакти у `components/layout/Footer.tsx`, дані у `data/content.ts`, а ліцензовані фото — у `public/images` або відповідних компонентах. Форма має клієнтську валідацію та імітацію надсилання.
