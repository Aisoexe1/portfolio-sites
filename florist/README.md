# Fleur Room

Флористична студія українською мовою. Запуск: `npm install`, `npm run dev`. Перевірки: `npm run lint`, `npm run typecheck`, `npm run build`. Дані букетів — `data/content.ts`; контакти — `components/layout/Footer.tsx`; форму замовлення потрібно з’єднати з CRM у `components/ui/OrderForm.tsx`.
